# webtech-assignment04

A web-based Markdown slide presentation application featuring a split-screen editor, real-time preview, and local storage persistence.

## ✨ Features
* **Split-Screen Interface:** Code your markdown on the left and see the real-time rendered slides on the right.
* **Easy Slide Separation:** Simply use `---` on a new line to separate your content into distinct slides.
* **Local Storage Persistence:** Your slides are saved directly to your browser's internal memory. Close the tab and come back later without losing your work!
* **Presentation Mode:** Immerse your audience with a distraction-free, full-screen presentation view.
* **Responsive Controls:** Navigate using on-screen buttons or keyboard shortcuts.

## 🚀 Getting Started
Since this project is completely client-side, there are no servers or dependencies to install.
1. Clone this repository or download the ZIP file.
2. Open the `index.html` file in any modern web browser (Chrome, Edge, Firefox, Safari).
3. Start typing your Markdown in the left pane!

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| **Ctrl + S** | Save slides to browser memory |
| **Arrow Left** | Go to the previous slide |
| **Arrow Right** | Go to the next slide |
| **F11** | Toggle Full Screen / Presentation Mode |

## 🛠️ Built With
* **HTML5** - Structure and layout
* **CSS3** - Styling and responsive design
* **Vanilla JavaScript** - Logic, local storage, and DOM manipulation
* **Marked.js** - For parsing Markdown into HTML via CDN
